# 🌐 Barangay Document Automation Promo Website

Welcome to my final project for **Web Systems and Technology**! This website is a personal promotional site built with **React.js** and **Tailwind CSS**, designed to showcase and promote another system I developed — an **Automated Barangay Document Management System**.

## 📌 Project Overview

This promotional site introduces visitors to a comprehensive system I built aimed at **streamlining the process of requesting and managing barangay documents**. It serves as both a portfolio piece and a practical introduction to the project's features, goals, and benefits for local communities.

### ✨ Features of the Promo Website

- 🧑‍💻 **About Me** – A short introduction to the developer (me!) and my passion for tech and community-driven solutions.
- 📸 **Project Showcase** – Highlights of the Barangay Document Automation System, with screen recordings and key features.
- ⚙️ **Technology Stack** – Explanation of tools and frameworks used in both the website and the system.
- 📞 **Contact Section** – Lets interested parties reach out for inquiries or collaborations.

## 🛠 Tech Stack

This project is built with:

- ⚛️ **React.js** – For building a dynamic, component-based user interface.
- 🎨 **Tailwind CSS** – For rapid UI styling and responsive design.
- 💡 And other supporting tools/libraries (e.g. React Router, icons, etc.)
